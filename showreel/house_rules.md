# House rules (appended to every show-reel prompt)

- One file, `demo.py`. `python demo.py` opens the interactive window.
- Dependencies: numpy and interactive_pipe only, unless the prompt names PyTorch. No image files: build the inputs in code.
- Stay under the line budget given in the prompt (blank lines, comments and docstrings are not counted, so do write a short module docstring). Short and readable beats complete: a student should be able to read the whole file in five minutes.
- Every control must visibly change something, and the default values must already show the phenomenon.
- Dragging a slider must stay fluid: a refresh should take well under a second.
- Name filters, controls and outputs after the concept they illustrate, and give each output a title.
